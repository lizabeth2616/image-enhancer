### Техническое задание (проект)

---

#### 1. Наименование

Система улучшения изображений в реальном времени на базе машинного обучения в браузере.

#### 2. Назначение

Веб-приложение принимает изображение пользователя, с помощью нейросети определяет оптимальные параметры яркости, контрастности и цветности, применяет их и возвращает улучшенное изображение. Вся обработка выполняется на стороне клиента (в браузере).

#### 3. Функциональные требования

**3.1. Загрузка изображения:**
- Поддерживаемые форматы: JPG, PNG, BMP, HEIC
- Максимальное разрешение: 15 Мп
- Способ загрузки: drag & drop, выбор файла через диалог

**3.2. Обработка:**
- ML-модель анализирует уменьшенную копию (224×224) и предсказывает 3 параметра: яркость, контрастность, цветность
- Параметры применяются к полноразмерному изображению через Canvas API
- Обработка асинхронная, в Web Worker, без блокировки интерфейса

**3.3. Выгрузка результата:**
- Скачивание в исходном формате (JPG/PNG) или конвертация в JPEG
- Предпросмотр с возможностью сравнения «до/после»

**3.4. API модуля:**

| Метод | Вход | Выход |
|-------|------|-------|
| `enhance(blob)` | Blob изображения | `taskId: string` |
| `getStatus(taskId)` | taskId | `{ status, progress }` |
| `abort(taskId)` | taskId | `boolean` |
| `getResult(taskId)` | taskId | `Promise<Blob>` |

**События:**
- `task-status-change` — `{ taskId, status, progress }`

**3.5. Информирование о ходе:**
- Статусы: `pending → decoding → analyzing → enhancing → encoding → completed`
- Прогресс: число от 0 до 100

#### 4. Нефункциональные требования

| Параметр | Требование |
|----------|------------|
| Максимальное время обработки 15 Мп | ≤ 30 сек |
| Среднее время обработки 8 Мп | ≤ 5 сек |
| Размер решения (HTML + JS + модель) | ≤ 10 МБ |
| Поддерживаемые браузеры | Яндекс, Chrome 90+, Firefox 90+, Edge 90+ |
| Блокировка интерфейса | Отсутствует (Worker) |
| Потребление RAM | ≤ 512 МБ на одно изображение |

#### 6. ML-модель

- **База:** MobileNetV2 (предобученная, ImageNet)
- **Голова:** GlobalAveragePooling → Dense(128) → Dropout(0.3) → Dense(64) → Dense(3)
- **Вход:** 224×224×3, нормализация в [-1, 1]
- **Выход:** [brightness_shift, contrast_shift, saturation_shift]
- **Размер в TF.js:** ≤ 4 МБ

#### 7. Порядок разработки

1. Генерация синтетического датасета (Python)
2. Обучение модели (Python/TensorFlow)
3. Конвертация в TensorFlow.js
4. Реализация API модуля (JavaScript)
5. Реализация Web Worker пайплайна
6. Реализация UI
7. Тестирование и оптимизация
