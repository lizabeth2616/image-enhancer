# 🎨 Улучшение изображений — ML в браузере

Система улучшения изображений в реальном времени на базе машинного обучения. ИИ анализирует изображение и подбирает оптимальные параметры яркости, контрастности и цветности. Вся обработка выполняется **прямо в браузере пользователя** без отправки данных на сервер.

---

## 📋 О проекте

Курсовой проект. Тема: «Разработка системы улучшения изображений в реальном времени посредством запуска ML-модели в браузере пользователя».

**Параметры улучшения:**
- ☀️ Яркость
- 🔲 Контрастность
- 🌈 Цветность

**Поддерживаемые форматы:** JPG, PNG, BMP, HEIC

**Максимальное разрешение:** 15 Мп

**Среднее время обработки:** < 1 секунды

---

## 🧠 ML-модель

Модель анализирует изображение по статистическим характеристикам:
- Средняя яркость пикселей
- Стандартное отклонение (контраст)

На основе анализа подбираются оптимальные параметры коррекции.

**Обучение модели:** [Google Colab](https://colab.research.google.com/drive/1-uqfKiIPgWFY_V3JFBknLqv-8DKPxSmc?usp=sharing)

В Colab ноутбуке:
1. Генерация синтетического датасета (500 изображений → 2500 пар)
2. Обучение MobileNetV2 с регрессионной головой
3. Конвертация в формат TensorFlow.js

---

## 🚀 Запуск проекта

### Способ 1: Локальный сервер (рекомендуется)

1. Распакуйте архив с проектом
2. Откройте терминал в папке проекта
3. Запустите сервер:
   ```bash
   python -m http.server 8000
   ```
4. Откройте в браузере: `http://localhost:8000`

### Способ 2: Открыть напрямую

Просто откройте `index.html` в браузере.
